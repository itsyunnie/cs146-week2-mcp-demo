# CS146 Week 2 MCP demo

This repository contains synthetic Issues used to demonstrate a student-built
GitHub Issue Assistant MCP server. It contains no application source or real login
system. A login/session bug described in an Issue is a fictional test scenario.

The server code, OAuth implementation, tests, evidence and writeup are maintained
separately in the course assignment repository.

The demonstrated workflow is: search Issues → read the Issue and discussion →
preview a reply → publish an explicitly approved comment.
